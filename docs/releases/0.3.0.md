# Adventurers 0.3.0 — 创世地质演化与文明区域预生成

新星球现在经历 16 个地质阶段：球面板块搬运地壳、碰撞抬升、河流侵蚀与沉积改变大陆和水系，生态在地貌变化次日开始响应。文明在末期地貌稳定后选址，投放前按预算生成出生地与文明周边区块。

本版是开发预发布，继续优先推进世界生成。Release 从已验证的 PR 分支提交构建，发布不代表 PR 已合并。

## 安装与体验

需要 **Minecraft 26.3 / Forge 66.0.9 / Java 25**。下载 `adventurers-0.3.0.jar`，替换客户端和服务器 `mods` 中的旧版模组；用随附 `SHA256SUMS` 校验。升级前备份整个世界。

1. 新建“冒险人星球（小 / 中 / 大）”。现有星球保留原算法，新的阶段演化需新建世界。
2. `/advent atlas` 领取阶段演化图，观察大陆、山地、河网和生态；下方金条显示进度。
3. `/advent genesis` 查看地质阶段、预生成区块数和文明条件。完成后使用 `/advent civilizations` 与 `/advent join <编号> born|summoned|transmigrated`。

新增参数包括 `genesisTicksPerDay`、`pregenerationRadius`、`pregenerationBudget`、`magicDensity`。默认每 5 个服务器 tick 推进一个创世日、每轮地质持续 12 日；默认预生成出生地和各文明周边 5×5 区块，最多同时请求 2 个区块。冷区不会因此创建 NPC 实体，荒野仍按探索加载。重启会重建队列、复用已有区块，完成/失败/停服均释放临时加载请求。

## 兼容性与实际范围

核心仍使用格式 2，继续读取格式 1 / 2 存档。0.2.1 星球保留算法 1、地形、城邦与身份；新世界使用算法 2。旧版模组不能读取算法 2 星球，降级需恢复完整旧备份。

地质历史在首次生成区块前确定；地图和抽象生态逐阶段推进，**实际方块统一采用末期地貌**，避免探索时间或线程顺序产生接缝。地图是离散阶段展示，尚无独立创世 UI 或连续动画。物种尚不反过来改变地质，投放后继续生态/文明模拟，但不重塑已有方块。

仍未实现：投放后地形重塑、洋流及逐区块动态气候、跨边界无缝视野、反向重力、上下位面无缝切换、多核心末地、元素/精神/亡魂位面、宇宙和天体生成。NPC 社会关系、知识传承、探索护送、炼金装备依既定顺序继续开发。

## 验证

32 项核心检查通过；普通预设与实际星球预设分别通过 10 项真实 Forge GameTest，无失败或跳过。覆盖历史地貌变化、生态滞后、创世中途存档继续、并行生成、真实已发布旧档兼容，以及地图更新、FULL 区块请求预算、去重、重建队列和票据清理。星球回归同时以两个处理器运行。标签发布流程会再次构建、运行两种服务器测试并生成校验文件，通过后上传附件。

没有执行交互客户端画面、长期多人负载或其他操作系统验证。
