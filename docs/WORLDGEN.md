# 世界生成：0.3.0

本版对应 `CONTEXT.md` 3.1–3.3 与 `SYSTEMS.md` 2.2 的一部分：地质阶段、地貌/生态交替、文明选址及混合加载。完整位面、天体系统及投放后的地形重塑仍待开发。

## 体验流程

1. 新建“冒险人星球（小 / 中 / 大）”，设置种子。旧世界保留旧地形算法，不自动转换。
2. `/advent atlas` 领取演化图并手持观察。每个地质阶段改变大陆、山地与河流；图下金条表示进度。
3. `/advent genesis` 查看地质阶段、区块预生成完成数、文明投放条件。普通玩家也可查看。
4. 全部 16 阶段结束、文明达到目标时代且周边地形预生成完成后，服务器提示“文明已涌现”。使用 `/advent civilizations` 和 `/advent join <编号> born|summoned|transmigrated` 选择身份。

地质阶段每 12 个模拟日一次，总计 192 日。每轮先改变地貌、水文和矿化，生态次日响应，特质筛选在两轮地质之间进行；文明可能需要继续演化才能出现。默认每 5 个服务器 tick 推进一日，正常 20 TPS 下地质阶段约 48 秒，后续文明等待时间取决于种子与投放条件。达到最大生成日数仍不满足条件时不会凭空生成文明，管理员可查看状态并继续推进。

投放后切回每服务器 tick 一个模拟 tick，24 游戏日为一年。睡眠和 `/time set` 暂不推进模组时钟。

## 配置

Forge 世界配置为 `serverconfig/adventurers-server.toml`。要在新世界启动前指定这些参数，可将模板放入服务器的 `defaultconfigs/adventurers-server.toml`，再创建世界。种子和大小分别通过原版种子/世界类型设置。

| 键 | 默认值 | 作用 |
|---|---:|---|
| `cityLimit` | 4 | 新模拟最多城邦数，1–64 |
| `magicDensity` | 1.0 | 新模拟保存的魔力恢复基准，0–8；不改变区块中的矿脉或植被 |
| `insertionEra` | 0 | 投放时代，0 石器至 6 信息时代 |
| `genesisDayLimit` | 2048 | 自动生成日数上限，达到后需管理员检查 |
| `genesisTicksPerDay` | 5 | 每个加速模拟日所用服务器 tick，1–100；增大可延长观察 |
| `pregenerationRadius` | 2 | 出生地及每座存续城邦预生成半径，单位区块，0–4；默认 5×5 |
| `pregenerationBudget` | 2 | 同时进行且每 tick 新启动的区块请求上限，1–8 |
| `workBudget` | 32 | 每 tick 模拟系统批次预算；同一时间戳执行完整 |

预生成只请求完整地形，不创建冷区 NPC 或运行其实体 AI。荒野继续按探索加载；跨边界足迹先归一化，多个城邦重叠的区块只入队一次。完成和停服后释放临时加载请求。重启重新计算待办，已经生成的区块直接读取，不重建玩家修改。生成失败会暂停并在 `/advent genesis` 与日志中报告；排除磁盘或区块加载错误后重启可重新执行队列。

## 地形一致性与限制

新算法在区块生成前重建完整、确定的地质历史。每轮板块沿球面旋转，搬运已有地壳；相向运动导致抬升，前一轮汇水决定侵蚀与下游沉积，水汽输送产生山脉雨影。没有额外噪声高度场替换这些结果。

地图和区域生物模拟依次经历历史帧；**实际 Minecraft 区块统一采用末期地貌**，包括创世期间玩家所在的区块。这样先探索、后探索、并行生成及存档重载都使用同一地形。地图是离散阶段预览，尚不是在玩家脚下重塑方块的现场动画。生物响应地貌，目前不会反过来改变地质历史。

0.2.1 的算法 1 原样保留，旧星球不显示 16 阶段地质变化；可以使用新的区块预生成队列。核心存档仍是格式 2，以种子、算法版本和模拟时钟重建阶段，生态/城市/玩家从持久状态恢复。仅支持算法 1 的旧版模组不能读取新算法 2 星球。

| 摘录主题 | 本版状态 | 仍缺少 |
|---|---|---|
| 世界生成/地质演化 | 球面板块历史、抬升、侵蚀沉积、阶段地图、生态滞后、投放条件 | 独立参数 UI、连续动画、投放后方块重塑、双向地貌/生物反馈 |
| 星球大小/环绕 | 三种大小、经度循环、过极点转换、载具乘客保存 | 跨界视野与装饰/玩家方块镜像同步 |
| 时序与加载 | 全局概览、出生地/文明附近预算预生成、荒野按需生成 | 任意瞬移后的轮廓到细节渐进呈现 |
| 文明选址 | 避开水面、陡坡，综合水源/矿化/魔力/温湿度 | 文明扩张、迁城及动态地形下的重新选址 |
| 气候/物质 | 海拔、纬度、水汽、雨影影响群系/区域生态；地质阶段更新矿化 | 洋流、海陆昼夜热差、地下水、逐区块动态气候 |
| 位面/重力 | 下界和末地继续使用原版生成器 | 反向重力、地心穿越、多核心末地、元素/精神/亡魂位面、无缝切换 |
| 宇宙/星系 | 尚未实现 | 恒星/行星/卫星/黑洞生成、宜居带和星系演化 |

本版没有交互客户端画面或长期多人性能验证；服务器验证覆盖真实地图数据、区块生成与加载流程。
